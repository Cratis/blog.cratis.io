POST (copy, adjust to taste)

We build Cratis Studio on Cratis. Chronicle, Arc, Components, AuthProxy and Ante, the same packages you can install.

I wrote up how it's put together:

- an edge (AuthProxy) that handles sign-in, organization and identity, so no service rebuilds it
- an event store per service, and facts passed between them instead of calls
- an organization that is a Chronicle namespace, so each tenant's events, observers and read models live apart
- one invitation followed from the first command to the last reactor

The part I like best: most of it is boring. Commands produce events, read models are projections, follow-up work is a reactor. That's the point.

Full walkthrough with the diagrams in the first comment.
