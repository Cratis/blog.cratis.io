# Cratis Blog

Essays and engineering explainers on event sourcing, CQRS and the open-source (MIT) Cratis stack.

- Read the blog: https://blog.cratis.io/
- Documentation: https://www.cratis.io/
- Source code for the Cratis projects: https://github.com/Cratis

## Running locally

The site is built with [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/).

```shell
npm ci
npm run dev
```

Posts live in `src/content/docs/blog/`. Run `npm run build` to produce the static site in `dist/`.
